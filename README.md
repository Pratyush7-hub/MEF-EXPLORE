# MEF-Explore

## Communication-Constrained Multi-Robot Entropy-Field-Based Exploration

This project implements a multi-robot exploration framework for exploring an unknown environment under communication constraints.

## Current Implementation

The project currently includes:

- 2D occupancy grid environment
- Multiple robot positions and movement
- Local map generation through sensing
- Dynamic communication graph
- Communication-based map sharing
- Local map merging
- Frontier detection

The MEF-Explore exploration strategy and autonomous exploration will be implemented and evaluated as the project progresses.
